# @huddle/web

React + Vite frontend for Huddle. Run from the repo root with `npm run dev:web`, or `npm run dev` to start everything. It opens on http://localhost:5173.

## Config

Copy `.env.example` to `.env` if the API isn't on `http://localhost:3001` (`VITE_API_URL`).

## How it's put together

| Where | What |
|---|---|
| `src/lib/api.ts` | Typed API client (`openapi-fetch`). Adds the access token, and on a 401 refreshes once and retries. |
| `src/lib/api-schema.d.ts` | Generated by `npm run gen:api`. Don't edit by hand. |
| `src/lib/auth.tsx` | `useAuth()`: login, register, logout, the current user. Tokens live in localStorage. |
| `src/lib/socket.ts`, `src/hooks/useSessionSocket.ts` | One Socket.IO connection. The hook joins a session, keeps the timeline and who's online, and catches up after reconnects. |
| `src/components/ui/` | Button, Input, Card, Badge, Avatar, ThemeToggle |
| `src/components/Can.tsx` | Renders children only if the role allows the action. Controls a role can never use are hidden, not disabled. |
| `src/index.css` | Design tokens (light and dark) used as Tailwind colors: `bg-surface`, `text-muted`, `border-line`, `bg-accent`… |

## Testing the silent token refresh

Start the API with a short access token: `ACCESS_TOKEN_TTL=30s npm run dev`. Wait a minute and click around. Requests keep working, and the network tab shows one call to `/auth/refresh-token`.
